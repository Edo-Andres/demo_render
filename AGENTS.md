# Demo de soporte

- Aplicacion FastAPI y HTML para consultas sobre pedidos y politicas ficticios.
- Mantener versiones fijadas en pyproject.toml y uv.lock y el modelo actual.
- Validar entradas y reglas con Python. No confiar permisos al modelo.
- No incluir credenciales, .env real, datos personales ni sesiones en Git.
- Conservar documentos e indice sincronizados; no modificar fragmentos sin regenerar sus vectores.
- Ejecutar uv run python -B -m unittest discover -s tests antes de entregar.
- Este repositorio es una copia de entrega; las funcionalidades se desarrollan y comprueban en su proyecto de origen y luego se transfieren aqui.
